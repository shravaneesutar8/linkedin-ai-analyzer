📌 AI-Powered LinkedIn Profile Analyzer (Gemini)

🚀 Project Description
This project is an AI-powered LinkedIn Profile Analyzer that uses Google Gemini API to evaluate a candidate’s LinkedIn profile and provide improvement suggestions. It also generates a professional PDF report.

✨ Features
Analyze LinkedIn Headline

Evaluate About Section

Check Skills relevance

Review Experience details

Suggest recruiter-friendly keywords

Provide overall profile score

Generate PDF report

📥 Input

LinkedIn Headline

About Section

Skills

Experience

🧠 AI Technology Used

Google Gemini API

Python

🛠️ Installation

Bash

pip install streamlit

pip install fpdf

pip install google-generativeai

▶️ How to Run

Bash

streamlit run app.py

📊 Output

AI analysis report

Improvement suggestions

PDF download report
